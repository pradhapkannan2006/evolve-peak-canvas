# FitPulse Dashboard

Role: Act as a senior UI/UX designer specializing in modern fitness and health dashboard interfaces.

Task: Generate a high-quality visual mockup of a modern fitness dashboard web application.

Context: Design a professional desktop fitness dashboard with a clean, futuristic interface. Include a left sidebar with Dashboard, Workout, Exercises, Progress, Nutrition, Goals, and Settings. The main dashboard should contain a welcome section, daily workout summary, calories burned, steps, active minutes, heart-rate overview, weekly activity chart, workout progress, fitness goals, and recent activities.

Design: Use a modern dark interface with clean cards, subtle gradients, rounded corners, glassmorphism elements, elegant typography, and well-organized spacing. Add professional fitness-related icons and simple data visualizations.

Visual Elements: Include workout statistics, circular progress indicators, weekly bar/line charts, goal completion indicators, exercise cards, and a small profile section. Make every component clearly readable and visually balanced.

Lighting & Style: Premium SaaS dashboard aesthetic, futuristic but practical, clean UI, subtle glow effects, polished visual hierarchy, professional product-design presentation.

Quality: High-resolution, sharp UI elements, realistic desktop browser presentation, pixel-perfect layout, consistent spacing, modern UX, professional portfolio quality.

Constraints: No clutter, no distorted text, no unnecessary 3D objects, no excessive animations, no unrealistic medical claims, no messy layout. Keep the interface realistic and suitable for an actual fitness web application.

Output: A polished desktop fitness dashboard UI mockup, 16:9 composition, professional presentation.
